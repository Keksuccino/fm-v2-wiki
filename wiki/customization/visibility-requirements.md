# 0. About

This page focuses on visibility requirements, which can be used with almost every element type and with whole layouts.

Visibility requirements can be used to check if a specific mod is installed, a world is loaded, the window has a specific size and much more.

> You can **hover** over the **Toggle** button of visibility requirements to get a **description** tooltip with information about how to use the requirement and what it does.
{.is-info}


# 1. Accessing the Visibility Requirements Controls

<br>

## 1.1. Elements

To access the visibility requirement controls of an element, **right-click** the element and click on **Visibility Requirements**.

![Screenshot_1](https://user-images.githubusercontent.com/35544624/219218680-86a465ea-e379-4f1f-adec-baa9a8f15120.png)

## 1.2. Layouts

To access the visibility requirement controls for layouts, **right-click** the **editor background** and click on **Visibility Requirements [Layout-Wide]**.

![Screenshot_3](https://user-images.githubusercontent.com/35544624/219220329-ad6bbf80-e6b0-4181-b935-eabb58eba262.png)

# 2. Adding Visibility Requirements to Elements/Layouts

When in the visibility requirement controls, add a requirement to the element/layout by **enabling** it.

![Screenshot_4](https://user-images.githubusercontent.com/35544624/219221033-9650aa89-9d89-4c70-80a6-370bab048679.png)

## 2.1. Show If | Show If Not

This is to specify when the requirement should be met.

For example, if you check for **Is Singleplayer** and you're **not** in singleplayer, the requirement will be met if set to **Show If Not**.

![Screenshot_5](https://user-images.githubusercontent.com/35544624/219221798-cdaafc51-618a-4ba3-bcbf-6e345ae34ef1.png)

## 2.2. Values

Some requirements need you to input a value.

![Screenshot_6](https://user-images.githubusercontent.com/35544624/219222541-5207e080-c023-42e3-a051-b1b9952cad29.png)

These values support [placeholders](./placeholders) by clicking on the little **Plus** button at the right side of the text input box.
