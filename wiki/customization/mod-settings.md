# 0. About

FancyMenu's settings are filled with various options to customize the behaviour of the mod itself, but it also has special options for specific menus like the main menu, which aren't possible with the normal customization system.

# 1. Edit the Settings
That's kind of an easy task. You can edit FancyMenu's settings directly in Minecraft by clicking on the little FancyMenu (FM) logo in the [Customization Helper](./customization/customization-helper) menu bar or the [Layout Editor](./customization/layout-editor) menu bar.
It's the first item in both menu bars.

![FM_settings](https://user-images.githubusercontent.com/35544624/111092430-5a9e8b00-8536-11eb-88f3-17f71f5cafac.png)

# 2. Where to find the Settings/Config File

In case you want to manually edit the config file, it is located at `.minecraft/config/fancymenu/config.txt`.

> If you don't know how to find the `.minecraft` folder, please take a look at [this Minecraft wiki page](https://minecraft.gamepedia.com/.minecraft).
