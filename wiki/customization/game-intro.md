# 0. About

You can set [animations](./animations) as "game intro" to play them before the main menu is displayed for the first time.

# 1. Set Animations As Game Intro

To set one of your [animations](./animations) as game intro, just set its [identifier](./animations#h-31-unique-animation-identifier) as **Game Intro Animation** value in the [FancyMenu settings](../mod-settings).

Now the animation will play after the game and animation loading process is done and before the main menu is displayed for the first time.
