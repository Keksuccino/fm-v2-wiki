# 0. About

This guide will focus on how you can export your whole FancyMenu setup, including all layouts, resources and configs, so other people can easily import your setup to use it.

# 1. Export Setups

To export your setup, just start the game and click on the **Setup** tab of the customization menu bar.

![](https://user-images.githubusercontent.com/35544624/167275765-bc27b45b-ac2e-4d37-936c-c200e8476c4d.png)

Then search for the **Export** option and click on it.

![Screenshot_1](https://user-images.githubusercontent.com/35544624/167275777-e13ea2ab-3c7d-4beb-a1ac-00e51b8da856.png)

This will start the export tool.

![Screenshot_2](https://user-images.githubusercontent.com/35544624/167275798-1a491eaa-fb7f-4061-95f5-138dac7cfd85.png)

After the setup got exported, click on **Confirm** to open the setup folder.

![Screenshot_3](https://user-images.githubusercontent.com/35544624/167275818-798c69c9-10b5-47ee-a70e-348cbccd25c7.png)

There should be a folder with the name you gave your setup earier.
This is your exported setup.

![Screenshot_5](https://user-images.githubusercontent.com/35544624/167275894-32a7b95e-90d4-40a7-903f-06a734cc097b.png)

If your want to share the exported setup with others, it is recommended to pack it to a ZIP.
**The other person needs to unpack the ZIP to import the layout.**

# 2. Import Setups

> Importing a setup will **completely overwrite** your current setup!
FancyMenu creates backups before importing a setup, but it's still recommended to **manually create a backup** of your Minecraft instance folder before importing a setup.
{.is-warning}

To import a FancyMenu setup, just start exactly like when exporting a setup, but instead of clicking on the **Export** option in the **Setup** tab, use the **Import** option.

![Screenshot_6](https://user-images.githubusercontent.com/35544624/167275998-961205dc-73dc-4b67-ab89-c274cd008d48.png)

If you want to import a setup that's not in FancyMenu's setup folder, you need to use the **Enter Path To Setup** option.

![Screenshot_7](https://user-images.githubusercontent.com/35544624/167276104-37eb1ca4-2694-496b-bfdc-0bbe6df11c90.png)

Keep in mind that you need a working FancyMenu setup, if you want to use the import feature.
Valid setups are folders, containing a folder named `setup` and a file named `setup.properties`.

![Screenshot_8](https://user-images.githubusercontent.com/35544624/167276185-627c4e60-fca6-40c8-b280-50a238760de3.png)

Just follow the instructions of the import tool here. It will guide you through the whole process.

If everything worked, you will see a popup telling you that the setup got imported succesfully.
Now just **restart the game** and you're done.

![Screenshot_9](https://user-images.githubusercontent.com/35544624/167276234-a3031f8b-5656-412c-aabd-f4c540f88c91.png)
