# 0. About

This guide will focus on how to change the background textures of vanilla/mod buttons and custom buttons added by FancyMenu.

# 1. Accessing the Button Background Options

To change the textures of your button, you first need to open its button background options.

To open the background options, **right-click** the button element and click on **Button Background**.

![Screenshot_6](https://user-images.githubusercontent.com/35544624/169872998-53e29f0a-5092-4e5b-895b-073eb0a2806c.png)

# 2. The Button Background Options

The button background options allow you to set the normal (when the mouse is not hovering over the button) and hover textures of a button.

![Screenshot_1](https://user-images.githubusercontent.com/35544624/169873548-d0486173-6e71-4f44-b13f-e87bed6a2f85.png)

The first section is for setting the **normal** background texture.
This is the one you see when not hovering over the button.

![Screenshot_7](https://user-images.githubusercontent.com/35544624/169873862-bde9c660-abcd-4879-b112-bf0f08983b7d.png)

The second section is for setting the **hover** background texture.
Like the name says, this is the one you see when hovering over the button.

![Screenshot_8](https://user-images.githubusercontent.com/35544624/169873993-aad41eff-5e33-4d5b-92ff-97c943ffc147.png)

# 3. Switching to a Different Background Type

Images aren't the only type of background you can set to buttons.
FancyMenu allows you to **animate** your button backgrounds!

To do this, just use the arrow buttons on the background type switcher to switch to the **Animation** background type.

You can use different types for the normal and hover backgrounds.
For example, you can set an **Animation** as normal background and an **Image** as hover background.

![Screenshot_3](https://user-images.githubusercontent.com/35544624/169874527-5e17c532-ce77-43ee-b014-17326654a320.png)

# 4. Saving your Changes

When you're done editing your button backgrounds, just click on **Done** to close the options.

![Screenshot_5](https://user-images.githubusercontent.com/35544624/169875170-91edbabb-4b2f-482a-8e6f-2bfa91c162c6.png)

Then **save your layout** via **Layout -> Save**.

![Screenshot_9](https://user-images.githubusercontent.com/35544624/169875496-5fafbc1d-3dde-4435-bca3-4ed8ba491a95.png)
